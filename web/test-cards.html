\(\displaystyle \text{Simplify: } \dfrac{a^{4} \cdot a^{-6}}{a^{-3}}\)
Answer
\(\displaystyle a\)
Complex Problem
\(\displaystyle (A(BC))_{il}\)
\(\displaystyle ((AB)C)_{il}\)
\(\displaystyle \text{Both } A(BC) \text{ and } (AB)C \text{ are } m \times q \text{ matrices. Compare entries using the definition } (XY)_{ij} = \sum_k x_{ik}y_{kj}:\)
\(\displaystyle = \sum_j a_{ij}(BC)_{jl} = \sum_j a_{ij} \sum_k b_{jk}c_{kl} = \sum_j \sum_k a_{ij}b_{jk}c_{kl}\)
\(\displaystyle \text{Both double sums range over the same finite index sets and sum the same terms } a_{ij}b_{jk}c_{kl}, \text{ just in a different summation order, so they're equal for every } i, l. \text{ Hence } A(BC) = (AB)C.\)
